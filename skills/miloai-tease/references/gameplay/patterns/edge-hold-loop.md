# Edge / hold / release loop

## Design profile

- **Role:** Anchor or modifier pattern
- **Best for:** endurance, denial, repeated escalation and relief, control over pacing
- **Typical scale:** scene / phase
- **Can lead a phase:** Yes
- **Player mainly:** approaches a threshold, reports reaching it, holds or stops, recovers briefly, then repeats
- **Combines well with:** `metronome-stroking.md`, `edge-cum-permission.md`, `timed-challenge.md`, `surrender-option.md`

This pattern is a repeated state cycle rather than a single instruction:

```text
build pressure → reach edge → hold/stop → short recovery → repeat or resolve
```

Vary duration, pace, recovery, or required number of cycles to create escalation. Keep the player's reporting action clear when the runtime cannot detect the threshold automatically.
