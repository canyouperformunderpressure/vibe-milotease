# 写作指导 (Writing Guide)

目标风格：**控制度高、强互动性、去套路化、直白干练的成人风格。** 
本指南是 Milo 作品内容创作的通用准则，**适用于作品中的全部文本**：包括角色对白、场景旁白、动作与感官描写、UI 选项与按钮文本、通知提示、机制反馈以及成人/NSFW 交互内容。

---

## 一、 通用语言规范与去 AI 化 (Humanizer)

1. **拒绝廉价 AI 模板与“文艺腔/网文腔”**
   - 严禁浮夸、矫揉造作的辞藻堆砌（如“深邃的眼眸”、“玩味的冷笑”、“饱满圆翘的蜜桃”等千篇一律的网文词库）。
   - 严禁模板化的神态与动作套话（如动辄“嘴角勾起一抹玩味的弧度”、“居高临下地俯视”、“封死所有退路”）。
   - 剔除泛滥的副词、形容词修饰。描写与口令一律保持**直白、干练、清晰、具有物理落地感**。

2. **严禁破折号滥用与标点套路**
   - 严禁滥用破折号（—/–）制造虚假停顿或装模作样的戏剧感。
   - 避免机械的“三段式”排比（如连续三个形容词、连续三个短语列举）。
   - 避免生硬的感叹号轰炸，力量来自词句本身的动作和压力，而非标点符号。

3. **严格规范比喻修辞与杜绝“感官缝合怪”**
   - **禁止解释性比喻：** 已经完成客观白描的动作、事件或心理，严禁再追加一层主观比喻进行重复说明。
   - **限定比喻对象：** 严禁以比喻形式描写角色的**语气、声音、腔调、眼神与视线**（成语除外，严禁出现“眼神像鹰隼般锁定……”之类的伪深刻比喻）。
   - **杜绝 AI 词汇生硬拼凑（感官缝合怪）：** 严禁将解剖部位名词与环境词生硬乱搭（例如“缝隙在幽暗水光”、“肉瓣在暗色水光泛着诱人光泽”等脱离人类感知与自然物理的怪诞词组）。描写必须符合人类真实的触感、光影与生理直觉。

## 二、 严禁提示词、机位与系统机制泄露

1. **绝对禁止角色口述生图提示词与镜头机位**
   - **典型恶性违规：** 角色把 Stable Diffusion / Midjourney 提示词、机位方向、身体姿势指令当成台词念出来（例如：“双手抓着自己两瓣臀肉回头看你”、“后方视角下的阴唇全部敞开”、“冲浪板架在肩后正面看你”）。
   - 角色是场景中活着的人，绝不是 AI 生图模型的提示词朗读者。角色的台词必须是符合其动机与当下情绪的真实口语，姿势变化与视觉画面应由**画面自身和旁白**自然承载，而非让角色在对白里给自己报幕。

2. **严禁正文中泄露提示词标签与标记括号**
   - 严禁在正文中出现 `【全裸正面展现】`、`【终极特写】`、`【阶段一】` 等生图标签、分镜指示词或中括号元标签。面向玩家的文本必须是纯净、沉浸的叙事。

3. **严禁角色扮演系统说明机与报表机**
   - 严禁角色在对白中解释界面或系统规则（例如：“右边挂着 [ 我要离开…… ]，只要你的理智还够，随时能点”）。
   - 严禁将判定与惩罚直接写成后台日志或管理条例（例如：“未经许可擅自射精，按严重违规处置（意志 -25）”）。
   - 机制的压力必须通过**角色的即时情绪反应（斥责、冷笑、惩戒）**与**玩家身体承受的生理挫败感**在情境中自然传达，而非粘贴系统报表。

## 三、 叙事结构、分场与节奏设计

1. **破除“一页一句对白+一句环境”的机械流水线**
   - 严禁将全篇拆解为僵死单调的刻板格式（如连续十几个 Page 全都是“一句台词 + 一句环境旁白 + 计时器 + 跳转”）。
   - 叙事必须拥有自然的呼吸与起伏：
     - 有时需要先交代环境氛围、动静与距离，再展开人物交互；
     - 有时角色连续两三句试探、嘲弄与诱导，不需要每句都强插一句环境旁白；
     - 有时画面与节拍的推进只需要简短的动作或纯粹的凝视压迫；
     - 合理合并紧密关联的小节，切忌为了凑页面数而制造机械重复的流水线碎片。

2. **场景引入与沉浸代入：以“你来到了……你看到了……”为感官锚点（拒绝上帝视角）**
   - **强化第二人称沉浸：** 叙事必须以玩家的直接感官体验为第一视角（“你踏上长满青苔的腐朽栈道，海风夹着潮气扑面而来。在波光微晃的浅滩处，你看到了……”）。让玩家真切感知到自己身处的空间与体感，而不是像个局外人在看画廊图说或第三方观察报告。
   - **严禁抽离的上帝视角与图说体：** 严禁出现“红发小魅魔背对海浪，右手轻抚颈后长发，勾勒出紧致腰臀”这种场外看客般的说明书式文字。是谁在看？从哪里看？必须写成玩家视线移动与感官注意力的自然捕捉。
   - **拒绝突兀指令，角色的反应必须顺应玩家的到来：** 严禁一进门没有任何前置交互就突兀地甩出一句机械口令（如进门劈头盖脸一句“站好！”）。角色如何听到你的脚步声、两人如何视线交汇、她带着怎样的表情打量你的靠近，必须合乎生活常理与心理预期。
3. **禁止超维/全知剧透句式**
   - 叙事必须严格立足于当前时刻的感知与局部信息。
   - 严禁使用“他/她不知道的是……”、“这预示着……”、“后来的事实证明……”等上帝视角预告句式。

4. **单句单意图**
   - 一句口语对白通常只承载一个主要的交流意图。
   - 不要试图让单句话同时承担动作播报、背景交代、任务下达、威胁与挑逗等多重功能；如有需要，拆分至多个节拍。

## 四、 角色心理与意志底线（情绪降级机制）

1. **维持理智与行动力底线**
   - 严禁角色表现出彻底绝望、精神崩溃或放弃生存意志。
   - 面对绝境、强敌或极端诱惑压力时，**强制将情绪反馈降级为：【警惕 / 紧张 / 咬牙坚持 / 寻求对策】**。
   - 角色无论处于何种劣势，必须始终保有基本的理性判断与应对意图。

2. **根据受众定位处理内心世界**
   - **开放式代入：** 留出空间由玩家自主产生情绪与归属感，不强加未经铺垫的主观结论。
   - **预设角色扮演：** 允许描写符合人设的心理波动与主观判断，但禁止在缺乏充足铺垫的情况下，直接给出不可逆的情感或意志沦陷定论。

## 五、 角色对白规范：做出反应，而非进行解释

1. **聚焦即时互动与动机一致性**
   - 角色的对白应当针对玩家刚刚做出的具体动作、迟疑、顺从、违抗、失误或状态改变做出即时反应（如观察、评判、纠正、惩奖、质问）。
   - 角色言行必须严格扎根于自身的人设、动机与当前情境，拒绝为了强行推动机制而说出脱离性格的台词。
   - 避免抽象的主题概括或舞台宣誓词，避免在登场或转折时强行使用宏大的预告片式收尾金句。

2. **拒绝无能狂怒与情绪失控（气场与张弛法则）**
   - 无论角色的性格定位是冷淡、高傲、掌控、病娇还是温柔，角色的威慑感与支配力来自其立场的坚定与心理上的从容，而非靠歇斯底里的咆哮、骂街或低劣的人身攻击。
   - 严禁动辄对玩家大吼粗鄙字眼或无意义的赶客咒骂。即使面临冲突或施加惩戒，台词也应当体现角色的理性、目的性或掌控感。
   - 保持口语化与节奏张弛，避免将每句话的情绪与压迫感都拉满到极致，留出呼吸与心理博弈的空间。

3. **声音独特性与拒绝通用模板**
   - 拒绝千篇一律的通用模板词库。不同角色的用词习惯、句式长短、说话节奏与情感距离必须具备鲜明区分度，严禁所有角色共用一套同质化的对白模板。
## 六、 场景旁白与动作描写规范

1. **承载物理感与必要信息，拒绝堆砌辞藻**
   - 旁白用于交代空间转变、动作连贯性、环境反差与即时感官信息（水温、光影、风声、肌肉紧绷、粗重喘息）。
   - 精简旁白的方式是**剔除无意义的冗余修饰与套话**，而不是**抹杀场景所必需的氛围与物理事实**。

2. **白描优于修饰，动作优于评价**
   - 用具体的动作和物理交互推动场景，避免直接给结论（写“手指陷入湿冷的木柱”，而不是“她显得十分动人”）。

## 七、 成人与 NSFW 交互写作规范

1. **去教学化与去体检报告化**
   - 严禁将亲密/调教场景写成生物课、体检报告或解剖记录。
   - 严禁在正文中罗列敏感带说明、等级参数或机制原理。
   - 真实感来自角色性格、动作是否合理、谁在嘴硬、谁在试探、谁先沉不住气，而不是解剖学名词的机械堆砌。

2. **词汇直白自然，服务于剧情与关系**
   - 使用直接、清晰、符合情境的词汇，不刻意使用做作的修饰代称（如“花径”、“玉液”），也不为了露骨而机械复读脏词。
   - 亲密互动是情节与角色关系的延伸，必须服务于当前的事件、人物温差或局势推进，拒绝与剧情脱节的纯器官运动流水账。

3. **严守身体常识与空间逻辑**
   - 姿态、距离、接触先后、发力点必须符合真实的身体结构与空间方位。
   - 一处孔穴同一时刻不能容纳多个物体。动作描写绝不能与角色当前的物理站位或先后时序产生冲突。

## 八、 UI 与交互文本规范

1. **选项与按钮文案自然融入情境**
   - 选项（Choice Labels）和按钮文本应体现玩家当下的行动意图或反应（例如：`「咬牙撑住」`、`「移开视线」`、`「松开手」`），避免生硬的机制代号。
   - 提示文案与状态说明应简洁凝练，保持作品的沉浸氛围。

## 九、 终审自检清单

在采纳任何文本前，逐项核对：

- [ ] **全文本适用检查：** 对白、旁白、UI、选项和系统提示是否全面符合本规范？
- [ ] **结构与流水线检查：** 是否打破了“一页一句对白+一句环境”的机械公式？场景引入是否有合理铺垫而非突兀命令？
- [ ] **动机与气场检查：** 角色言行是否符合其设定与当前动机？是否存在突兀粗暴的无能狂怒、骂街或情绪失控？
- [ ] **提示词与机位泄露检查：** 是否存在角色口述生图提示词、镜头机位或身体报幕的现象？是否存在 `【】` 标签？
- [ ] **去系统说教检查：** 角色是否变成了系统说明书？惩罚是否被写成了冰冷的系统日志报表？
- [ ] **词汇自然度检查：** 是否杜绝了“缝隙在幽暗水光”这类生拼硬凑的感官缝合怪？
- [ ] **标点与修辞检查：** 是否排除了滥用的破折号（—/–）？比喻是否合规且未应用于声音与眼神？
- [ ] **叙事视角检查：** 是否严格立足即时视角，无全知剧透？
- [ ] **意志底线检查：** 面对劣势与危机，角色是否保持了理智、警惕与应对意图？
- [ ] **角色独特性检查：** 声音与支配风格是否鲜活独特，而非通用 AI 模板？
